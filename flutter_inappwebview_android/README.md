# flutter_inappwebview_android_kontext

Kontext-maintained Android WebView implementation for the `flutter_inappwebview_kontext` plugin family.

## Usage

Add a dependency on [`flutter_inappwebview_android_kontext`](https://pub.dev/packages/flutter_inappwebview_android_kontext)
to use the Android-specific APIs directly. The package automatically registers
with Flutter when included in a project.
